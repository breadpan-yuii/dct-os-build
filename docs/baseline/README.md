# Firmware / Secure Boot baseline reports

One file per machine: `<hostname>.txt`.

Generated by:

```bash
make baseline        # this machine -> docs/baseline/<hostname>.txt
```

These are **project evidence**, not build artefacts — commit them.
They populate the firmware register referenced in `docs/proposal.md` §7 Phase 0
and Appendix B.

## Procedure

1. Run on every in-scope classroom PC, before any change.
2. Name the file after the machine's asset tag if it has one, e.g.
   `lab1-pc01.txt`, so it matches the inventory.
3. Collect the trailing `MACHINE|...` line from each into one CSV:

   ```bash
   make summary        # regenerates docs/baseline/summary.csv
   ```

   `make baseline` already does this for you after each audit.

4. Paste the CSV into the proposal appendix and delete the `[[TODO]]` in §6.4.

## What to look for

| Verdict | Meaning for deployment |
|---|---|
| `ENABLED` | Nothing to do |
| `DISABLED` | Nothing to do — the signed chain boots anyway |
| `DISABLED+SETUPMODE` | Note it; back up firmware keys before any change |
| `LEGACY` | **Blocker** — a UEFI-only image will not boot; plan a firmware switch |
| `UNKNOWN` | Re-run as root |

Do not put these files anywhere with real credentials or console logs — they
contain hostnames and firmware versions only.
