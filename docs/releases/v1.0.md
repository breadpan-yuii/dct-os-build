**This replaces the first upload of `v1.0`.** That image booted correctly, but
its own `/md5sum.txt` still described the base Ubuntu image, so

builder now rewrites the entries it invalidates; this image verifies clean.
If you downloaded before 19 Nov 2026, download again.

## Why the download is in four parts

GitHub blocks any single file over 100 MiB in git and over 2 GiB as a release
asset, so the ISO is published as four parts, each under 2 GiB. The parts are
plain byte ranges of the same file — no special tool, no archive, nothing to
extract.

Download all four into one directory, then reassemble.

**Linux / macOS**

```bash
cat Dominican-OS-1.0-live-amd64.iso.part-* > Dominican-OS-1.0-live-amd64.iso
sha256sum Dominican-OS-1.0-live-amd64.iso      # macOS: shasum -a 256
```

**Windows (PowerShell)**

```powershell
cmd /c copy /b Dominican-OS-1.0-live-amd64.iso.part-0+Dominican-OS-1.0-live-amd64.iso.part-1+Dominican-OS-1.0-live-amd64.iso.part-2+Dominican-OS-1.0-live-amd64.iso.part-3 Dominican-OS-1.0-live-amd64.iso
```

The result must be exactly 7,530,217,472 bytes and hash to the SHA-256 above.
If it does not, one part is corrupt — check the part checksums.

## Write it to a USB stick

```bash
sudo dd if=Dominican-OS-1.0-live-amd64.iso of=/dev/sdX bs=4M status=progress oflag=sync
```

`/dev/sdX` is the **whole device**, not a partition (`/dev/sda`, not
`/dev/sda1`). Get it wrong and you overwrite a disk. An 8 GB stick is
borderline at 7.53 GB; use 16 GB.

## What this image does

- Boots to a branded live desktop. The Ubuntu installer does **not** auto-open.
- The launcher entry **Install Dominican OS** starts Canonical's installer with
  DCT artwork. Nothing is written to the disk unless you install.
- Login screen, GRUB label, plymouth splash and wallpapers are purple/gray.
- The early-boot splash is DCT's, not Ubuntu's — the initrd is rebuilt and its
  casper hooks and medium UUID are re-synced with the image.
- Ships OnlyOffice (default), LibreOffice (fallback) and Wine.

## What it does not do

- **It does not include Microsoft Office.** Office 2016 installs only from
  DCT's own licensed media; see `docs/office.md`.
- It has never been installed from end to end, never run on real classroom
  hardware, and Secure Boot has not been tried on a physical machine.
- No data on idle RAM on a 4 GB machine yet.

## Verified before publishing

```
test-live-iso.sh --serial     3 passed, 0 failed, 0 warnings
test-live-iso.sh --structure 15 passed, 0 failed, 0 warnings
md5sum -c md5sum.txt (mounted) 302 entries, 302 OK, exit 0
```

The serial test deliberately omits `ignore_uuid`, so casper's real medium
detection is exercised: it matched the initrd's UUID against the ISO's
`/.disk/casper-uuid-generic` and assembled the layer chain. It reaches a live
desktop with the hostname `dominican`.

The `md5sum -c` run mounts the finished image read-only and verifies every
entry the way `casper-md5check` does at boot — the check the first upload
failed.
